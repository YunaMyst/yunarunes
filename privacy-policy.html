Política de Privacidade — YunaRunes

Última atualização: 25 de setembro de 2026

O YunaRunes é uma ferramenta independente para consulta e utilização de recursos relacionados com Summoners War: Sky Arena. Esta política explica como os dados são tratados na aplicação YunaRunes e no site yunarunes.com.

1. Dados pessoais

O YunaRunes não exige criação de conta, nome, palavra-passe, contactos, localização, câmara, microfone ou acesso aos ficheiros do dispositivo para utilizar as suas ferramentas.

2. Dados armazenados no dispositivo

Algumas funcionalidades do site podem utilizar armazenamento local do navegador para guardar preferências, favoritos ou definições. Esses dados permanecem no dispositivo/navegador e não são utilizados pelo YunaRunes para identificar pessoalmente o utilizador.

3. Ligação à Internet

A aplicação Android utiliza a Internet para carregar o conteúdo e as ferramentas do YunaRunes. Como acontece com qualquer ligação à Internet, o serviço de hospedagem e os fornecedores de rede podem processar dados técnicos necessários para entregar o conteúdo, como endereço IP, data/hora e informações técnicas da ligação, de acordo com as respetivas políticas.

4. Partilha de dados

O YunaRunes não vende dados pessoais e não utiliza os dados do utilizador para publicidade personalizada.

5. Serviços de terceiros

O conteúdo do YunaRunes pode utilizar serviços de hospedagem, distribuição de ficheiros e recursos externos. Esses serviços podem processar dados técnicos da ligação necessários para fornecer os respetivos recursos.

6. Crianças

O YunaRunes não solicita deliberadamente dados pessoais de crianças. A aplicação não exige uma conta nem recolhe diretamente informações pessoais para funcionar.

7. Segurança

São utilizadas ligações HTTPS para os recursos do YunaRunes sempre que disponíveis. Nenhum sistema de transmissão ou armazenamento eletrónico pode ser considerado absolutamente seguro.

8. Alterações

Esta política poderá ser atualizada quando houver alterações relevantes na aplicação, no site ou nos requisitos legais. A data de atualização será alterada no início desta página.

9. Contacto

Para questões relacionadas com privacidade ou com o tratamento de dados no YunaRunes, utilize os canais de contacto disponibilizados no site yunarunes.com.

10. Relação com a Com2uS

YunaRunes é um projeto independente e não é afiliado, patrocinado ou endossado pela Com2uS. Summoners War: Sky Arena e respetivas marcas pertencem aos seus respetivos proprietários.
