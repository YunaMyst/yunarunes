## Full description — Português
YunaRunes reúne ferramentas para ajudar jogadores de Summoners War: Sky Arena a consultar monstros, runas e conteúdos de forma rápida.

### O que encontras
• Base de dados de monstros.
• Páginas individuais com informações do monstro.
• Builds e conjuntos de runas.
• Calculadora de runas.
• Otimizador de runas.
• Team Builder para montar equipas.
• Sugestões de sinergia entre monstros.
• Códigos promocionais ativos.
• Ferramentas adicionais para jogadores.

A aplicação YunaRunes é uma forma prática de aceder às ferramentas do projeto num dispositivo Android.
